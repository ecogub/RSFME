2026-07-28 | M9a: Switched Linear Interpolation to RiverLoad method6 (Option A)
- Decision: Nic chose Option A — use method6 (true linear interpolation) instead of method1
  (averaging). Function renamed calculate_pw -> calculate_li for clarity.
- Rationale: the paper's architecture depends on linear interpolation being one of the four
  archetypal methods — it appears in the title framing, Figure 1's illustration, Equation 2,
  the Aulenbach framework being tested, and the decision tree. Options B (method3,
  period-weighted) and C (keep method1, rename to averaging) would each have required
  rewriting the Methods, dropping the Appling/Aulenbach citations that justify linear
  interpolation, and would have left the paper evaluating three methods plus two variants
  of averaging.
- Diagnostic evidence that method1 was wrong: the sign of the old 'pw' bias tracked the
  inverse of the C:Q slope in every series (diluting Ca overestimated ~+20%, enriching NO3
  underestimated ~-37%) — the signature of an estimator that discards cov(C,Q). At zero
  coarsening on Plynlimon it was still +22.6% off, which is impossible for an interpolating
  estimator holding the complete record.
- Smoke test confirms the fix: on a complete daily HBEF series calculate_li returns exactly
  the hand-computed sum(C*Q*86400) and 0.00% error vs truth for Ca, against method1's
  +19.57%. For NO3 it returns -0.86% where a naive paired sum gives -11.20%, the difference
  being method6 correctly interpolating the 4-day June gap.
- Method key renamed 'pw' -> 'li' across 9 files including plot_theme.R colour/label maps
  and the load_annual.csv method column.
- Side effect that forced a scope expansion: the existing NEON conductivity .RData files
  store method='pw', so with figure scripts now looping over 'li', Figures a1-a4 would have
  rendered empty. Restoring 'spCond' to the NEON solute loop (06_coarsen_analysis_neon.R)
  became mandatory rather than optional, which also closes the reproducibility gap where
  conductivity results could not be regenerated from the checked-in code.
- Also resolves the decision-framework branch collapse: 'li' is now genuine interpolation
  while 'average' remains mean(C) x mean(Q over all days), so the two branches are
  substantively different for the first time.
- Full rerun launched: calculate_annual_flux.R (29 domains) then 00_run_all.R scripts 01-12.
  Pre-rerun outputs backed up so old-vs-new deltas can be quantified for the text pass.
